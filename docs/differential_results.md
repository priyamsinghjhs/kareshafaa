## Limits (honest)

* Agreement means the engine matches **the rules document as independently re-implemented**. A misunderstanding of
  a guideline that is written into the document itself is not detected; that needs clinical-lead review.
* The input vocabulary (unit spellings, HPV/cytology words, BI-RADS formats, statuses) is a shared interface
  specification, and the generator samples from it plus junk. Real lab messages may contain spellings neither
  implementation knows; those go to review (fail-safe) but are not covered by this rate.
* The rate is per randomised result under a boundary-weighted generator, not a per-patient real-world error rate.
