One click creates a synthetic patient and plays a realistic journey through the real workflow (HL7 result → Arabic teach-back → rejected referral; T1 escalation to L4; two-key transfer; unreachable ladder; Ramadan no-show).

Suggested 5-minute demo

  1. Coordinator (Aisha): work queue sorted by SLA → urgency → ML outreach priority; open an overdue case, see the timeline, owner and audit.
  2. Patient (Arabic / Hindi / Urdu / English; Tagalog speaker sees the interpreter notice): read the result in plain language, pass the teach-back, ask to talk to a clinician.
  3. GP (Dr Omar): order a confirmatory test, refer, answer an e-consult; try to close without evidence – it is blocked.
  4. Specialist: accept or reject a referral with a reason; book; mark attended / no-show.
  5. Clinical lead: dashboard (before/after simulation, fairness), governance (approve or roll back a model, approve rule changes).
  6. Analyst: aggregates only, small cells (<5) suppressed.

Safety by design

  • The state machine is deterministic; AI never changes a case state or closes a case.
  • Every read and write is in an append-only, hash-chained audit trail.
  • Model promotion and rule changes need a clinical lead's approval.
  • Messages are simulated and never sent.
